公开基准与测量协议Public benchmarks and measurement protocol


青冥 Qingming Flat2 Benchmarks 是跨设备的精确向量检索（Exact Vector Search）公开基准。每项性能对照限定在同一设备、同一数据集和同一测量协议内，报告 GPU Event 与 Host API 延迟、批量 QPS、Top-K 正确性、CPU FP64/FP32 数值审计与独立确认轮次的原始采样。


Qingming Flat2 publishes within-device exact vector search comparisons with GPU and host API latency, batch QPS, Top-K correctness, CPU FP64/FP32 numerical audits and raw holdout samples. It does not rank devices against one another.
